# GLOSSARY — 设计术语 → 语义 → 代码转化表

用户用非正式产品语言描述需求（中文、口语、截图描述）。本表把高频术语映射到语义和代码落点，动手前先查此表；表是活的，用户定版一条就补一条。

## 术语表

| 用户说法 | 语义 | 代码落点 / 现行定版 |
|---|---|---|
| 弹层 / 上拉菜单 | 底部弹出选择器 | 沿用既有上拉弹层模式（账户弹层、货币下拉等），不新造形态 |
| 对话框 / 确认框 | 居中模态对话框 | `AppDialog`（全项目统一，禁用 Alert） |
| 胶囊 / 药丸 | 圆角药丸形按钮/标签 | 形态定版：随长名加长不截断；具体高/字号以代码现状为准 |
| 开关 | 切换控件 | 设置页用 `SegmentedControl`；胶囊开关 = 关空心圈 / 开 ✓ 实心圆+发光描边 |
| 卡片 | 圆角容器 | theme.ts 卡片 token，深浅双主题各有一套 |
| 渐变大卡 | 线性渐变强调卡 | expo-linear-gradient；净资产/账户大卡用 `netWorthGradient*` 系列 token |
| 按压反馈 | 触感+缩放 | `PressableScale` 全局公用件，全项目统一按压反馈 |
| 触感 | Haptics 震动反馈 | expo-haptics 四档，按操作轻重选档 |
| 图标池 / 颜色池 | 类别可选图标与色板 | `src/constants/categoryAddOptions.ts`（两页共用），改池前必过 glyphmap 校验 |
| 选中态 | 已选项的高亮标识 | 类别网格选中=恒显原图标（不加 ✓）；日历选中日=常驻实底双圆环；具体形态先查已定版条目 |
| 金额渐缩 | 大金额自适应缩字号 | 记一笔 Hero 金额：位数多时缩放，货币钮字号固定不随缩；具体基准以代码现状为准 |
| 收入色 / 支出色 | 金额语义配色 | 收入与支出用项目既定的语义色对，转账另有区分 |
| 空态 / 加载态 / 错误态 | 列表三种兜底状态 | 与既有页面同款式，统一补齐 |
| 中英文案 | i18n 双语 | useT 取词，zh/en 两个语言包同步补键 |
| 头部按钮间距 | 页头操作按钮间隔 | 用户校准定版勿改；具体数值以代码现状为准 |

## 设计术语转化表（主观感受类）

| 用户说法 | 语义 | 落地方式 |
|---|---|---|
| 呼吸感 | 留白充足、元素不拥挤 | 增大 padding/gap，用 spacing 令牌 |
| 更紧凑 | 缩小间距，信息密度提高 | 减小 gap 一档，不改字号 |
| 有质感 | 层次分明、细节精致 | 轻微阴影 + 1px 边框 + 圆角统一 |
| 更醒目 | 提高视觉权重 | 加大字重/对比度，不改布局 |
| 跟手/顺滑 | 交互反馈及时 | 加 transition 150–250ms |
| 卡片感 | 内容成组、有边界 | 背景色 + 圆角 + 阴影 |

## 使用规则

1. 需求命中本表 → 直接按"现行定版"实现，不要重新发明
2. 用户给出新形态并拍板 → 把新定版补进本表（注明日期）
3. 本表与代码冲突时，以用户最新拍板为准，并回写本表
4. 遇到表中没有的术语：先用一句话复述你的理解，等我确认再改
5. 数值一律使用项目现有 design tokens，不硬编码新值
6. 本表不誊抄具体数值：只记形态与原则，字号/尺寸一律以代码现状为准；每次修改随报告列出改动前后尺寸（见 AGENT.md「修改报告规则」）
